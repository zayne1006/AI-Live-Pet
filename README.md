# AI-Live-Pet

AI 悬浮窗桌宠 — 手机端，无需电脑

## 功能
- 🐱 SVG 小猫悬浮窗，随你移动
- 😸 8种情绪表情，自动切换
- 📱 App感知，知道你正在做什么
- 💭 孤独递进，越不聊天越主动找你
- ⏰ GitHub Actions 自动编译，无需本地 Gradle

## 快速开始
1. Fork 本仓库
2. GitHub Actions 会自动编译 APK
3. 下载 release 安装到手机

## 技术
- Android Jetpack Compose + WindowManager
- SVG 动态渲染
- Kotlin 协程
- Supabase 后端 (可选)
